## 数据口径

- 规则版本：7月27日版预警规则（唯一权威）
- 策略：A1（atmiv低侧变化率确认 + 2级共振门控）+ win-adapt 自适应
- 标的：AG 白银期权，15分钟频率
- IV 口径：Black-76 + Shibor 重算
